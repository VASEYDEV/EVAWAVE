## Status

**Pre-alpha, pre-implementation.** This repository currently holds the engineering
standard, governance documents, and a docs-only verification gate. No application code
has landed yet, so there are no features to list.

The product foundation arrives as an owner-supplied package plus a directive brief,
installed per [`docs/runbooks/package-intake.md`](docs/runbooks/package-intake.md).
This README is rewritten to the full front-page spec when it does.

## Quick start

Nothing to install yet. The fastest way in is the docs:

```bash
git clone https://github.com/VASEYDEV/EVAWAVE.git
cd EVAWAVE
bash scripts/gate.sh   # run the repo-standard verification gate
```
