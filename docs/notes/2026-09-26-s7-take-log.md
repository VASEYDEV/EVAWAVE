## Choices

- **Live engines only.** Udio is halted (A12), so nothing is rendered there to log. The
  IR's `EngineId` still includes it; the database is stricter.
- **Never the audio.** The reference is an engine-side id or link. The database refuses a
  `data:` URL and anything over 2,048 characters. The app refuses the same before sending.
  Only `https:` references render as links; anything else is shown as text.
- **Code points, not `maxLength`.** The review of PR #12 caught a native `maxLength`
  counting UTF-16 units. The take fields clamp by code points instead.
